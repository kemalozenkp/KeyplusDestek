# Security contact

Report Keyplus Destek vulnerabilities to **info@keyplus.com.tr**, operated by
Keyplus Yazılım Donanım Danışmanlık Ltd Şti. Do not include passwords,
private keys or customer session contents in a public issue.

Keyplus Destek is a RustDesk-derived Windows client. Its customizations and
the pinned upstream version are documented in README.md. Current downloads
are unsigned; SignPath approval and a signed distribution channel are pending.

The source tests and build/install tests described in this repository are
not an independent security audit. Actual signed releases must be verified
and tested after the signatures are applied.
